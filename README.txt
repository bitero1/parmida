سایت عاشقانه برای پارمیدا

فایل‌ها:
- index.html: صفحه‌ی اصلی و بخش‌های عاشقانه
- quiz.html: آزمون شناخت ابوالفضل
- special.html: بخش ویژه که پس از امتیاز کامل باز می‌شود
- style.css: طراحی واکنش‌گرا
- script.js / quiz.js / special.js: تعامل‌ها و منطق بازی

اجرای محلی:
فایل index.html را در مرورگر باز کنید. برای رفتار مطمئن‌تر localStorage و پیمایش بین صفحات، می‌توانید پوشه را با افزونه Live Server در VS Code اجرا کنید.

انتشار روی GitHub Pages:
1. فایل‌های این پوشه را به ریشه‌ی یک repository در GitHub آپلود کنید.
2. وارد Settings > Pages شوید.
3. در بخش Build and deployment، گزینه‌ی Deploy from a branch را انتخاب کنید.
4. شاخه‌ی main و پوشه‌ی /(root) را انتخاب و Save کنید.
5. آدرس منتشرشده‌ی GitHub Pages را باز کنید.

نکته: قفل بخش ویژه صرفاً برای بازی است و امنیت واقعی ایجاد نمی‌کند؛ پاسخ‌های آزمون در فایل JavaScript سمت کاربر قرار دارند. فونت از Google Fonts بارگذاری می‌شود و برای بارگذاری آن اینترنت لازم است.
